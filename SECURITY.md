# Security policy

Reeframe handles camera credentials, stream URLs and backend sessions, so
security reports are taken seriously.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security > Report a vulnerability** on this repository. Don't open a public
issue, pull request or discussion for it.

Include what you can of the following:

- the affected version or commit
- steps to reproduce, or a proof of concept
- the impact you expect (for example credential exposure or remote code
  execution)

You should get a first response within 7 days. Once the issue is confirmed,
a fix and an advisory are prepared together with you, and you are credited
unless you prefer not to be.

## Supported versions

Only the latest release receives security fixes.
